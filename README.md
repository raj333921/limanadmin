# limanadmin

A JavaScript-based admin application.

## Language Composition

- JavaScript: 98.8%
- HTML: 1.2%

## Getting Started

To get started with this project, clone the repository and follow the setup instructions.

```bash
git clone https://github.com/raj333921/limanadmin.git
cd limanadmin
```

## Installation

Install dependencies:

```bash
npm install
```

## Usage

Run the application:

```bash
npm start
```
